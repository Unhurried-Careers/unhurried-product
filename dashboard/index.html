Security & Pipeline Architecture Principles

Unhurried enforces complete separation between Continuous Integration (GitHub Actions) and Continuous Delivery (Google Cloud).

SLSA VERIFIED PROVENANCE

🛡 Zero-Credential CI Model

GitHub Actions runs strictly with permissions: contents: read and holds zero Google Cloud credentials or deployment keys. Ephemeral read tokens for unhurried-common are auto-revoked immediately.

🚀 Google Cloud Deploy Revisions

Continuous Delivery runs natively via Cloud Build 2nd-gen triggers on main and staging. Cloud Deploy manages immutable releases with automatic /health verification and 1-click rollback.

🔒 Secret Manager Boundary

All production and staging credentials (OAuth secrets, SMTP relay, Firestore bindings) reside exclusively in Google Secret Manager and are never stored in repositories or CI environments.
